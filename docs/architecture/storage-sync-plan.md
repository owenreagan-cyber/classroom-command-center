
## MongoDB Atlas Addendum

MongoDB Atlas is available through the teacher subscription and may be useful later.

Recommended use:
- Level 3 metadata backend
- lesson package records
- resource indexes
- Today Prep history
- playlist catalogs
- teacher settings
- sync logs

Do not use MongoDB for:
- large PDFs
- videos
- raw Apple Pencil ink blobs
- classroom audio recordings
- initial MVP storage

Do not rely on Atlas Device Sync / Realm Sync without a fresh review.

Preferred future pattern:
- local-first apps
- optional backend/API
- MongoDB stores metadata and references
- Drive/iCloud/NAS/local storage keep the actual large files
