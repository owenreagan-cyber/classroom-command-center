Command Center — one /control home

Merges the four current "home" surfaces (Teach Mode, Presentation Hub, Teacher Command Dock, Display Studio) into one screen, and adds a Classroomscreen-style bottom widget bar (tap an icon, it lands on the screen — see the redesign doc's Part 2.0 research) as the fast path for adding content. Tap-cost color-coded below:

green = always visible, 0 extra taps yellow = one tap away (drawer / popover) blue = rare settings, two taps, never on the main screen
MacBook width (1280px) — default state
Always visible, no scrolling: live display preview + Send/Blank/Restore, the scene rail to switch screens, a 4-across quick-launch grid for the daily-use tools (Timer, Noise, Picker, Display Screens — teacher's own favorites, swappable), and the edit/tools rail on the left. This single layout replaces Teach Mode's chrome-minimal shell, Presentation Hub's "Present" view, and the always-mounted-but-empty-until-edit-mode Command Dock aside — they are one screen now, not three that swap based on a hidden mode flag.

The bottom widget bar is new in this revision (Classroomscreen-style tap-to-add — see the redesign doc's Part 2.0/2.1). Tapping ⏱ Add Timer here drops a timer straight onto the live preview in its default rail slot — no drag from a sidebar, no intermediate "widget library" screen. If a timer already occupies that slot, the new one joins it as part of the same timer group (one occupant, several timers inside — see the editing-model mockup) rather than being blocked or overlapping it.
One tap away — the single grouped tool drawer
Tapping "⋯" (More tools) opens one drawer with the tool registry (18 entries as recounted directly against toolRegistry.ts today — that number is a fact about current code, not a target this drawer is designed to hit) grouped by its existing daily / students / instruction / management categories — plus Clean Board's Spotify, Stamps, QR, and routine-prompt tools folded in as new entries in the same categories (not a second, separate dock), and lesson resources as a tab here instead of a full-screen mode swap. What stays visible in the favorites row above vs. lives only in this drawer is decided by this merged home screen's own layout, not by preserving any particular tool count. This is the only place any tool not already favorited lives — no more Teach Mode vs. Dashboard vs. Board Control vs. Display Studio guessing games about which surface has the thing you want.
