Command Center — /display zone system

Every preset below is built from the same shared grid, not hand-tuned x/y coordinates. This replaces the current template system, where each of the 9 built-in presets places objects at independently-chosen pixel positions (see templatePacks.ts) with no shared layout guarantee. Revised in this pass: the 5 zones are now default landing spots, not hard slots, and the old 4-widget cap is gone — see the updated rules and the 4th worked example below.

Zone rules (enforced in code, not by convention)

  • 5 zones remain, but as smart defaults now, not hard slots (revised): title, main, rail-1, rail-2, system, on a 1920×1080 canvas, 56px safe margin, sitting on top of a finer snap grid a teacher can place a widget on anywhere there's room — see the 4th worked example below.
  • No hard widget-count cap (revised — replaces the old "4 content slots" rule): overlap is prevented by the snap grid + a real-time collision check, not by capping the screen at 4 boxes. A widget group (e.g. a stack of timers) counts as one occupant of a zone regardless of how many widgets it contains — this is what makes Owen's real morning board (message + 3 timers + music) work without hitting an artificial ceiling.
  • One rail slot is reserved for "status" (music or a status/game widget, never both, never floating over the title) — this is where the current always-on Noise Defense HUD moves to: opt-in per screen, and only rendered while a noise-monitoring session is actively running — never on Assessment Mode, full stop.
  • Multi-timer routines collapse to one group (current step + up→next, or all steps visible as one occupant), instead of 3 stacked boxes — fixes the Morning Arrival — New Classroom preset's 3-timer rail, and is the same mechanism as the group-as-one-occupant rule above.
  • Minimum type scale, clamped in the data model: title ≥64px, main heading ≥40px, main body ≥32px, timer digits ≥56px, status/system text ≥20px — a widget cannot be saved below its floor.
  • System chrome (fullscreen toggle, sound-enable, connection dot) lives in one reserved 40px strip at the bottom edge, always in the same place, auto-dims after first interaction — never mixed into the content zones.
