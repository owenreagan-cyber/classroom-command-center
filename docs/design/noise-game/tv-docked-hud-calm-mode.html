Noise Game — docked HUD, every state (Calm Mode)

Calm Mode mutes all theatrics — no flashing, no screen shake, no jitter — while the underlying pressure/HP/ protocol logic keeps evaluating exactly as normal (§4.4 of the architecture doc). Every state below is the Calm Mode counterpart of the matching state in tv-docked-hud-states.html: same information, same color-plus-icon-plus-label signaling, but state changes are shown as a static highlighted border instead of a flash/pulse/shake animation. Appropriate for testing moments, guest observers, or any lesson needing full visual calm without losing the accountability mechanic.
