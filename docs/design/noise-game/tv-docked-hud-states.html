Noise Game — docked HUD, every state (dramatic treatment)

The default `/display` presentation: a compact card in one corner, coexisting with whatever the teacher has projected (the dashed placeholder box stands in for actual board content — never part of this feature). This gallery shows the dramatic/default visual treatment. See tv-docked-hud-calm-mode.html for the Calm Mode counterpart of every state below (no flashing, no shake). Every color-coded state is paired with an icon/shape/text label, never color alone. All character/villain representation is original geometric shapes + initials — no official artwork anywhere.
